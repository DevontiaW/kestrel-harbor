What does a trace show that a dashboard hides?

Your weekly report says jobs take "about two hours on average." Then a customer calls, upset, because their job took most of the day. Both are true. The average blends many jobs into one number, and it only counts the ones that finished.

An average tells you how long finished work took. A trace of one task tells you where its time went: how much was work and how much was waiting, and where.

A trace is a timeline for one piece of work. Each time the task moves, the system writes a line in a log: when it arrived, when each step started and ended, who reviewed it, and what stopped it.

Two averages appear in these lessons. Average time to finish counts only tasks that are done. Average time in the system counts every task that has arrived, done or not.

A different situation

An accounting firm reports that tax returns take "three days on average" from upload to filing. What single question would a trace of one late return answer that the average cannot?

Pick one late item from last week. Write down when it arrived, when each step started and ended, and who touched it. Add up the minutes nobody was working on it. That is your first trace.

The one rule

Time in the system = time working + time waiting. An average shows the total; a trace shows the split, and where the waiting happened.

Starter prompt

Start from the single-file queue simulator I built earlier (I will paste it below). Keep it one HTML file with no libraries. Add:

1. An event log. Each time a task joins a line, starts a step, or leaves a step, add a row: minute, task number, step, and what happened.
2. A minute-by-minute record for each task: for every minute from arrival to finish, was it working or waiting, and at which step?
3. A task picker and a timeline bar for the chosen task: one horizontal bar from arrival to finish (or to now), solid where it was working and striped where it was waiting, colored by step.

Show the log in a scrollable table under the bar. Compute every number on screen from the log, not from separate counters.

What "done" looks like

  • Pick any task and see its bar: work and waiting, step by step.
  • The log lists every move, in time order.
