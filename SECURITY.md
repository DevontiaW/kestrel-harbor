# Security

Kestrel Harbor runs entirely in your browser from local files. It has no server, no accounts and no network calls at runtime, and it stores no personal data.

## Reporting a problem

If you find a security issue (for example, a way for a crafted file or link to run code in the page), please report it privately through GitHub's private vulnerability reporting for this repository rather than in a public issue. Include the steps to reproduce and the browser you used. We aim to acknowledge reports within a week.

## Scope

In scope: the page, the lessons, the build script and the release audit. Out of scope: your browser, your operating system, and third-party libraries (report those upstream).
